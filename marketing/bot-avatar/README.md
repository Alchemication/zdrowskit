# Telegram bot avatar

Generated raster concept for the zdrowskit Telegram bot.

- `telegram-avatar.png` — 512 × 512 upload-ready export.
- `telegram-avatar-source.png` — full-resolution generated source.
- `telegram-avatar-40px.png` — actual-size legibility check.
- `telegram-avatar-v2.png` — revised 512 × 512 candidate with the paired
  diagonal forehead mark and broader circular-crop-safe shoulders.
- `telegram-avatar-v2-source.png` — full-resolution revised source.
- `telegram-avatar-v2-40px.png` — revised actual-size legibility check.
- `prompt.md` — generation and revision prompts.
- `prompt-v2.md` — revised edit prompt, using the earlier second pass as its
  image target.

The image uses the site's cream, near-black, olive, and orange palette. The
image model introduced minor tonal and antialiasing variations, so the PNG is
visually four-colour rather than a literal four-entry indexed palette.
