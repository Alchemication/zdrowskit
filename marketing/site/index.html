03 / Ask it anything

It queries your whole history, then answers.

The coach writes SQL against your own database, so questions are not limited to a fixed set of dashboard cards. Ask about a pace, a trend, or a correlation you suspect, and it goes and looks.

If a chart makes the answer clearer, it renders one and sends it back in the same conversation. Reply to a report, update your goals mid-chat, ask a follow-up.

04 / Every job gets its own model

The model that writes your report is not the one that checks it.

Each surface is scored against the same eval cases and routed to whatever measured best for that job — which is how the verifier ended up on the cheapest model here. It beat both premium options at catching bad claims, and being cheap is why it can check every report instead of a sample.

Every route has a fallback, so one provider having a bad morning degrades the answer rather than losing it.

New models land and prices fall constantly. Each candidate gets measured against the same cases, and a route moves when the numbers justify it — cheaper, better, or a trade written down in the open. Costs should keep falling from here.

What you need
  • Apple Watch + iPhone
  • An always-on macOS or Linux machine
  • Python 3.12+ and uv
  • Tailscale on the host
  • A Telegram bot
  • An LLM provider API key
What it costs to run

under $1 /month

LLM spend measured over six weeks of real use on the default models — weekly report, coach review, nudges and chat. Nearer $0.30 if you mostly leave it alone, around $1 if you chat with it daily.

Every job routes to the cheapest model measured to do it well. Over a year, on the same workload:

How that breaks down →

A household appliance,
not a health-data platform.

Raw history stays local

Each person’s Apple Health history lives in a separate SQLite database on your own machine. There is no zdrowskit server, no account, and no signup.

But your data does reach an LLM provider

Reports, nudges and answers send the relevant slice of your health data to whichever model provider you configure. If health data leaving your machine for an LLM API is a dealbreaker, this is not the tool for you.

The operator can read everything

Built for roughly 1–10 people who know each other. Profiles are added by hand-editing a TOML roster; whoever runs the host can read every hosted person’s database. Trust replaces the access controls a real multi-tenant service would need.
