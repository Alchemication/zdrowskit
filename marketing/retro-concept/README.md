# zdrowskit retro concept

Standalone marketing-page experiment. No project files were changed.

## View

Open `index.html` in a browser. It has no external dependencies or network
requests; the only asset is `assets/people-triptych.png`.

```bash
open marketing/retro-concept/index.html
```

## Construction

- HTML/CSS: layout, responsive behavior, terminal UI, arrows, labels, texture,
  buttons, and animation.
- Generated raster: the photographic human triptych. Its generation brief is
  saved in `image-prompt.txt`.
- `index.html.png`: macOS Quick Look thumbnail used for the initial visual
  check. It shows only the upper portion of the page.
